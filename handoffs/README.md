# Domain Handoffs

Concise continuation-state files for active domains, per the format in
`Agent-Context-Bootstrap-v1/Prompt.md`. Create one file per actively-evolving
domain — not for every folder, not for scaffold-only code.

Template:

```md
# <Domain> — Current State

## Status

## Architecture / Flow

## Key Files

## Important Decisions

## Dependencies

## Known Gaps

## Continue From Here
```

Keep each handoff ~40-100 lines: current-state oriented, not a changelog or
source dump.
